### Selected code

- **[YouTube social-network analysis](https://github.com/dhruv-ar/youtube_social_network_project)** — Rust graph-analysis project on a network with more than 1 million nodes and nearly 3 million edges. Implements adjacency-list parsing, BFS path analysis, community detection, centrality measures, parallel processing with Rayon, and tests.
- **[LocalBoost](https://github.com/dhruv-ar/LocalBoost)** — Collaborative Python/Flask project that accepts sales CSVs and produces forecasting and investor-analysis outputs. The [React/Vite frontend](https://github.com/dhruv-ar/LocalBoost-Frontend) lives in a separate repository.
